I build agentic tooling, monitoring systems, and publishing pipelines.

Software engineer working at the intersection of AI, systems, and market infrastructure. I use LLMs as cognitive infrastructure for research, writing, and execution, but I keep human judgment at the center.

## Building Now

- Agentic workflows for research, content, and software delivery
- Monitoring and automation systems for infra and market-facing tools
- LLM-native publishing pipelines built around human arbitration

## Selected Projects

**[jacqblog](https://github.com/0xjacq/jacqblog)**  
LLM-native publishing system for human-arbitrated writing. Built with Next.js, MDX, typed content loaders, and multi-channel publishing.

**[VaultMonitor](https://github.com/0xjacq/VaultMonitor)**  
Monitoring platform for DeFi protocols with Telegram alerts, rule-based probes, and operational visibility.

**[serversguru-deploy](https://www.npmjs.com/package/serversguru-deploy)**  
Autonomous VPS deployment CLI for provisioning servers, Docker, Nginx, and SSL through API + SSH workflows.

**[Yt2txt](https://github.com/0xjacq/Yt2txt)**  
GPU-accelerated YouTube transcription pipeline built on Faster Whisper and PyTorch.
